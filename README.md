# Lofi-Factory Automation Pipeline

A Python-based automation project designed to streamline the production and publishing of Lo-Fi music content.

## Key Features
- **End-to-End Automation:** Automates the pipeline from audio generation to video rendering.
- **API Integration:** Utilizes Google/YouTube APIs for automated metadata management and video uploads.
- **Content Scaling:** Designed to handle repetitive content generation tasks, reducing manual overhead.

## Tech Stack
- **Language:** Python
- **Core Logic:** Automation scripting, API integration, file processing.
